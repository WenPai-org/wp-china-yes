## 行为规格

以 `docs/specs/config-schema.md` 的 enum 与 `docs/4.0-rewrite-plan.md` §4.1 为准，冲突时以 spec 为准并在报告说明。

**PublicAssets**

| 配置值（`public_assets[]`） | 3.x 来源键（参考） | 上游主机示例 | 镜像目标（3.x 值，保持） |
|---------------------------|-------------------|--------------|-------------------------|
| `google_fonts` | `admincdn_public` ⊃ googlefonts | `fonts.googleapis.com` | `googlefonts.admincdn.com` |
| `google_ajax` | 同上 googleajax | `ajax.googleapis.com` | `googleajax.admincdn.com` |
| `cdnjs` | 同上 cdnjs | `cdnjs.cloudflare.com/ajax/libs` | `cdnjs.admincdn.com`（前缀被吃掉） |
| `jsdelivr` | 同上 jsdelivr；以及 `admincdn_dev` 的 unpkg/jquery 等 | `cdn.jsdelivr.net` 等 | `jsd.admincdn.com` |
| `emoji` | `admincdn_files` ⊃ emoji | Twemoji / s.w.org emoji | 3.x `prepare_emoji_replacements` |

白名单外 URL 原样返回。`MirrorHealth::is_healthy(host_of(target))===false` 时保留原 URL。未知视为健康（与 3.x `is_healthy` 一致）。`public.admincdn.com` / 站点自有 `wp-content` **不得**出现在映射表。

Emoji 为可选：数组不含 `emoji` 则不改。

**Avatar**（spec enum，不是 3.x 的 `cn/global/weavatar/off` 原样）：

| 4.0 值 | 行为 | 3.x 对照 |
|--------|------|----------|
| `cravatar_cn` | 换成 `cn.cravatar.com` | `cravatar=cn` |
| `cravatar_global` | 换成 `en.cravatar.com` | `cravatar=global` |
| `off` | 不挂钩 | `off` |

3.x `weavatar` 不在 4.0 schema enum 内。本任务**不实现** WeAvatar 线路。迁移映射由 M2-01 处理；若执行者发现产品需要第四档，停并写报告，由产品 feibisi 定。

钩子移植 `Avatar.php`：`get_avatar_url`、`avatar_defaults`、`user_profile_picture_description`，以及 3.x 已挂的 `um_user_avatar_url_filter` / `bp_gravatar_url`。替换源列表照 `replace_avatar_url` 的 `$sources`。

`enabled()` 尊重 `recovery_mode` 与 `Environment::allowsUrlRewrite()`。

## 与 3.x 的关系

移植函数：`Acceleration::prepare_public_library_replacements`、`prepare_dev_library_replacements`、`prepare_emoji_replacements`、`mirror_usable`；`Avatar::get_cravatar_url`、`replace_avatar_url`。`test-mirror-health-fallback.php` 若 M1-04 未搬完 host 解析，本任务补 PHPUnit 对应节。旧测试文件不改。

3.x `admincdn` 含 `admin`（wpstatic 后台核心文件加速）**不在** `public_assets` enum。是否进 4.0 首发 **待定（M0，产品）**；本任务不做 wpstatic 整站后台改写，避免把未进 schema 的能力偷运进来。

## 禁区

- 总计划 §0 不变量；不改 3.x `Service/Acceleration.php` / `Avatar.php` 运行时。
- 不恢复前台加速。不直写第三方商业域作导流。
- 禁止「遥测开关」、opt-in、「默认关闭」文案（反例）。
- 不写死套餐；公共库属受限免费层时只读 entitlement 钩子，无则按「未绑定仍可用或回源」——**具体层归属已定在定稿 §7.1c**（adminCDN 为受限免费），未绑定 / 配额用尽 → 保留原 URL，不得让站点坏。
