## 背景

可选集成。3.9.3 smoke 已钉死：stylesheet 含 `family=` 与 `subset=`，且**不得**带 `crossorigin`（提供方无 ACAO）。4.0 目录必须 API 获取并缓存。受限免费层：无权益 / 配额用尽回原始（不输出文风 link），站点不坏。

## 行为规格

以 3.9.3 smoke 断言与 `Service/Fonts.php` 为准；产品范围以 rewrite-plan §4.2 为准，冲突时以 smoke 为准并在报告说明。

输出（移植 `load_windfonts`）：

- preconnect `https://cn.windfonts.com`
- 保留授权注释（3.x 许可标注）
- 每条启用字体：`<link rel="stylesheet" href="{api/css?family=&subset=}">` **无** `crossorigin`
- `subset` ∈ `en|zh|zh-common|full`，默认 `full`
- API 基址 3.x：`https://app.windfonts.com/api/css`

4.0 目录：从 API 拉列表缓存，禁止把字体全家桶写死在 PHP 数组当长期真源。连接优化页字体族 DataViews 读该缓存（若 M1-08 已留 Toggle，本任务接上列表）。

RTL / `windfonts_reading` **不进入 4.0**（删除功能）；不移植 `init_rtl_mirror`。

3.x `windfonts=frontend|on|optimize` 在迁移里已收成布尔（M2-01）；本模块只有开/关。后台是否注入 stylesheet：开则前台+后台（对应 3.x `on`），**待定（M0）** 是否仅前台；未定前与 3.x `frontend` smoke 一致只挂 `wp_head`，并在报告写明。

## 与 3.x 的关系

移植：`Fonts::load_windfonts`、`build_font_css_url`、`extract_font_family_name`。

**必须保留的断言（`tests/wordpress-smoke.sh`）：**

```
family=wenfeng-hcszt
subset=full
不得出现 crossorigin
```

旧 smoke 在 3.x 路径上继续跑（写 `wp_china_yes`）。本任务另写 4.0 等价：在 `WPCY_KERNEL=v4` 下设 `modules.windfonts=true` 与字体列表后 `do_action('wp_head')` 同样三断言。**不要改** `tests/wordpress-smoke.sh` 里 3.x option 结构。

`tests/test-runtime-regressions.php` 文案 `'Windfonts output matches the current CSS API and avoids forced CORS'` 仍须被 legacy 跑过。

## 禁区

- 总计划 §0；不改 3.x `Service/Fonts.php`。
- 不硬编码长期字体目录。不加 `crossorigin`。
- 不移植阅读/RTL。
- 禁止「遥测开关」、opt-in、「默认关闭」文案（反例）。
- 额度不写死。
