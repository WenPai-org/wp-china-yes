## 行为规格

以 `docs/specs/apps-manifest-and-bridge.md` 与 `docs/design/admin-ui-spec.md` §3.3 为准，冲突时以 spec 为准并在报告说明。

信封：`{ wpcy: 1, type, request_id, payload }`。`wpcy!==1` 丢弃。宿主只接受 `event.origin === new URL(manifest.entry_url).origin`。不匹配：能回 error 则 `wpcy_apps_origin_mismatch`，否则静默丢弃。工具永远拿不到 REST nonce。

**mock 工具页 `tests/fixtures/mock-app/index.html` 行为清单（必须按序自动执行一遍，便于 e2e）：**

1. 发 `ready`（空 payload）。
2. 收 `init` 后请求 `context.get`。
3. `data.set` 写入一条 `{key:"smoke", value:{ok:true}}`，再 `data.get` 读回，再 `data.delete` 删除。
4. 请求 `entitlement.get`。
5. 请求 `go.open`。
6. 发 `resize`（height 整数，如 320；>4000 宿主截断）。

每步在页内 `data-testid` 或 `#log` 打一行，供 Playwright 断言。

**e2e 用例列表：**

| ID | 内容 | 期望 |
|----|------|------|
| A1 | 未绑定打开文派服务 | 空态「绑定后显示」；主动作「绑定本站」 |
| A2 | mock 绑定成功 | 圆点「已绑定」+ 后 8 位 |
| A3 | 权益表三态夹具 | 可用 / 已用尽 / 已到期 文案符合词表；非 active 显示「获取」且 href 以 `https://wpcy.com/go/` 开头 |
| A4 | 加载 mock 工具 | iframe sandbox 属性正确；工具 `#log` 含 ready |
| A5 | 读写删数据 | log 显示 set/get/delete 成功 |
| A6 | 无权益工具点击 | Modal 介绍 +「获取」，不挂 iframe |
| A7 | 跨 origin 消息 | 从其它 origin `postMessage`，宿主不写数据 |
| A8 | 索引不可达 | 琥珀「小工具目录暂时不可用」，绑定段仍在 |

`ready`/`resize` 不要求 permission。未声明 permission 的 `data.set` → error 码 `wpcy_apps_forbidden_permission`。

## 追加要求（2026-09-04）

- **桥接实现细节（规格 §3.1 / §3.1a 新增）**：宿主 origin 启动快照；校验 `event.source === iframe.contentWindow`；不向 `window.parent`/`window.top` 发消息、不把来自 parent 的消息当工具消息；`ready` 前消息丢弃；REST 转发 10s 超时回 `wpcy_apps_host_timeout`；写类消息不自动重试；`resize` 200ms 防抖。e2e 加双层 iframe 场景（外层模拟 chromeless、内层 sandbox 工具）。

## 禁区

- 总计划 §0；默认不拉生产 apps 索引。
- 不给 iframe `allow-same-origin`。不把 nonce 传入 iframe。
- 不在前端判断套餐（只渲染 entitlement 事实）。
- 禁止「遥测开关」、opt-in、「默认关闭」文案（反例）。
- 直写 weixiaoduo.com 禁止。
