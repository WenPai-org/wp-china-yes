# 任务 M2-01：Migration（3.x option 白名单、dry-run / 执行 / 回滚）

依赖：必须已合并 `main` 的 **M1-03**。并行组 **E**。预计 diff 规模：≤ 1000 行。基于分支 `main`。工作分支 `grok/m2-01`。

## 背景

## 行为规格

以 `docs/specs/config-schema.md` 与 `docs/4.0-rewrite-plan.md` §7.2 为准，冲突时以 spec / §7.2 为准并在报告说明。

**映射表（摘 §7.2）：**

| 3.x 设置 | 4.0 设置 | 规则 |
|----------|----------|------|
| `store` | `connectivity.wordpress_org` | `wenpai` → `auto`；`off` → `off` |
| `admincdn_files` | `connectivity.public_assets` | 仅迁移仍受支持白名单 |
| `admincdn_dev` | `connectivity.public_assets` | 合并并去重 |
| `cravatar` | `connectivity.avatar` | `cn` → `cravatar_cn`；`global` → `cravatar_global`；`off` → `off`；`weavatar` **待定（M0，产品）**：未定前记 ignored 并在报告列出，不得擅自映射到 cn |
| `windfonts`、`windfonts_list` | `integrations.windfonts` / `modules.windfonts` | 模块保留：`windfonts` 非 `off` → `modules.windfonts=true`；目录重新校验。4.0 schema 无 `integrations.windfonts` 明细键——字体列表存何处 **待定（M0）**；未定前只迁开关布尔，`windfonts_list` 进报告 `kept` 或独立 option **不要发明**，标 ignored_reason=`schema_pending` |
| `bridge` | 不直接迁移登录状态 | ignored |
| `adblock*` | `modules.notice_control` | `adblock=on` 或 `notice_control` 有值 → true；规则 JSON 本身 4.0 改由 wpcy.com 下发，旧 `adblock_rule` ignored |
| `telemetry` | 不迁移 | ignored（4.0 无此开关） |
| `telemetry_site_url` | 不迁移 | ignored |
| 其他字段 | 不迁移 | ignored + 原因 |

执行后新 option 通过 Validator。旧 `wp_china_yes` **不删**。备份含 `from_version`、`migrated_at`、`legacy_hash`、`ignored_fields`。回滚：用备份把 4.0 option 恢复到迁移前（通常是删除新 option 或写回 Defaults——**不得写回 3.x 结构进 `wp_china_yes`**）。可重复执行。

**六份 fixtures（键名来自文件，预期按上表）：**

### `single-3.6.2-01.json`（5 键）

- 键：`store, admincdn, cravatar, windfonts, adblock`

### `single-3.8-02.json`（15 键）
