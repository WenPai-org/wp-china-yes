# 任务 M1-10：e2e（Playwright：四页 + 恢复页 + 命令面板）

依赖：必须已合并 `main` 的 **M1-08**。并行组无（单独）。预计 diff 规模：≤ 700 行。基于分支 `main`。工作分支 `grok/m1-10`。

## 先读

- `docs/dev-plan/README.md` M1-10 行、M1 出口。
- `docs/design/admin-ui-spec.md` §2、§3.1–§3.5、§6。
- `docs/architecture/adr-002-admin-react-app.md` 验收条（Playwright 覆盖四页 + 恢复页）。
- `docs/dev/testing.md` 后台端到端节。
- `.github/workflows/ci.yml` 现状（M1-01 应已加 `quality`/`frontend`；本任务加 `e2e`）。
- `docs/dev/CONTRIBUTING.md` CI 门禁。

## 背景

M1 最后一个任务。门禁：wp-env 下安装 → 设置 → 诊断 → 恢复 → 退出恢复；旧 `framework/` 未被加载（`get_included_files()`）。为 M2-05 小工具 e2e 打底（本任务不测 iframe）。

## 行为规格

以 `docs/design/admin-ui-spec.md` 页面规格与 ADR-002 验收为准，冲突时以 spec 为准并在报告说明。

用例列表（每条一个 `test()`）：

| ID | 步骤摘要 | 期望 |
|----|----------|------|
| E1 | 登录管理员，打开 `?page=wpcy` | 标题「概览」或规格中的页标题；三卡区域存在 |
| E2 | 概览点「立即检查」 | 不报 JS 错；卡或「需要处理」更新 |
| E3 | 打开连接优化，改 avatar 为 off，保存 | Snackbar「已保存」；刷新后仍为 off |
| E4 | 打开文派服务占位 | 200，无 React 白屏 |
| E5 | 诊断点「立即检查」 | DataViews 出现至少一行目标 |
| E6 | 诊断「进入恢复模式」 | 到达 `?page=wpcy-recovery` |
| E7 | 恢复页无 JS：点「关闭全部 URL 改写」 | 绿 Notice「恢复模式已开启」 |
| E8 | 命令面板打开「打开连接优化」 | URL 含 `wpcy-connect` |
| E9 | `WPCY_KERNEL=v4` 激活后 `wp eval` `get_included_files()` | 路径不含 `/framework/` |
| E10 | 键盘：Tab 遍历连接页保存按钮 | 焦点可见 |

`wp-env` 必须定义 `WPCY_KERNEL` 为 `v4`（`wp-config.php` 常量或 `wp-env` `phpConstants`）。未定义时本套 e2e 应失败并在报告说明，不得改去测 3.x UI。

## 与 3.x 的关系

- 不改 `tests/wordpress-smoke.sh`（3.x 烟测仍过）。
- 不测 3.x 设置框架页面。
- legacy 29 必过。

## 禁区

- 总计划 §0；不改 3.x 运行时。
- 不在 e2e 里写「遥测开关」操作；禁止断言存在 opt-in、「默认关闭」控件（反例）。
- 不测真实 `apps.wpcy.com`。
- 不 push；不改 `docs/dev-plan/README.md`。

## 验收标准

1. `composer check` 全过（本任务 PHP 若无新类，unit 仍过即可）。
2. `npm run build && npm run test:e2e` 全绿。
3. CI 文件含 job 名 `e2e`。
4. `git diff --stat` 限于 `tests/e2e/`、`.github/workflows/ci.yml`、`package.json`/`package-lock.json`。
5. 提交信息前缀 `test(e2e): `（workflow 可另 commit `build: ` 或并入，但至少一条 `test(e2e): `）。
