## 行为规格

以 `docs/design/admin-ui-spec.md` 页面规格与 ADR-002 验收为准，冲突时以 spec 为准并在报告说明。

用例列表（每条一个 `test()`）：

| ID | 步骤摘要 | 期望 |
|----|----------|------|
| E1 | 登录管理员，打开 `?page=wpcy` | 标题「概览」或规格中的页标题；三卡区域存在 |
| E2 | 概览点「立即检查」 | 不报 JS 错；卡或「需要处理」更新 |
| E3 | 打开连接优化，改 avatar 为 off，保存 | Snackbar「已保存」；刷新后仍为 off |
| E4 | 打开文派服务占位 | 200，无 React 白屏 |
| E5 | 诊断点「立即检查」 | DataViews 出现至少一行目标 |
| E6 | 诊断「进入恢复模式」 | 到达 `?page=wpcy-recovery` |
| E7 | 恢复页无 JS：点「关闭全部 URL 改写」 | 绿 Notice「恢复模式已开启」 |
| E8 | 命令面板打开「打开连接优化」 | URL 含 `wpcy-connect` |
| E9 | `WPCY_KERNEL=v4` 激活后 `wp eval` `get_included_files()` | 路径不含 `/framework/` |
| E10 | 键盘：Tab 遍历连接页保存按钮 | 焦点可见 |

`wp-env` 必须定义 `WPCY_KERNEL` 为 `v4`（`wp-config.php` 常量或 `wp-env` `phpConstants`）。未定义时本套 e2e 应失败并在报告说明，不得改去测 3.x UI。
