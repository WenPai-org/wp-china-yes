## 行为规格

以 `docs/specs/entitlements.md` 为准，冲突时以 spec 为准并在报告说明。

响应形状：

```json
{
  "entitlements": [
    {
      "id": "wpcy-leaf-motusnap-100",
      "service": "motusnap",
      "tier": "limited-free",
      "status": "active",
      "quota": { "limit": 100, "used": 12, "period": "month", "resets_at": "2026-10-01T00:00:00Z" }
    }
  ]
}
```

| 状态 | 行为 |
|------|------|
| `active` | 正常 |
| `exhausted` | 相关模块切回原始上游 / 工具只读 |
| `expired` | 同 exhausted + 展示「获取」（`https://wpcy.com/go/{service}`） |
| 服务端不可达 | 最后一次缓存至多 72h，超时按基线层 |
| 任何状态 | 都不得让站点功能失效 |

缓存 1h transient。客户端不计算额度、不解析价格、不写死 `100`。认证如何附 credential **待定（M0，授权系统）**；mock 可用测试头，生产适配 M3。

`GET /entitlements`：返回缓存副本；不可达且无缓存 → `[]`，不 5xx。基线层（元数据镜像、驻留、诊断、Cravatar、广告拦截、本地设置）不看本状态。

四态测试：各态下 `Degrade::shouldUseUpstream('motusnap')` 布尔符合上表。
