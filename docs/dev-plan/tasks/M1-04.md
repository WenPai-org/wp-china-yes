免费连接优化的第一块。M1-06 诊断读本模块状态缓存；M1-08 连接优化页展示镜像状态。行为必须与 3.9.3 两份独立测试对齐，避免再把安装包打到元数据主机。

## 行为规格

以 3.x 测试断言与 `Service/Super.php` 为准；产品范围以 `docs/4.0-rewrite-plan.md` §4.1 为准，冲突时以测试断言为准并在报告说明。

移植常量语义（值保持 3.9.3）：

| 符号 | 3.x | 4.0 |
|------|-----|-----|
| API 源 | `Super::MIRROR_API_ORIGIN` = `https://api.wenpai.net` | 元数据 |
| 包源 | `Super::MIRROR_PACKAGE_ORIGIN` = `https://downloads.wenpai.net` | 安装包 / 语言包 |
| 探测路径 | `MIRROR_PROBE_PATH` = `/plugin/classic-editor.zip` | 打**包源**，带 Range，标自身请求 |
| 体积下限 | `MIRROR_MIN_PACKAGE_BYTES` = 1024 | 低于则不可用 |
| TTL | `MIRROR_UP_TTL` = 1h；`MIRROR_DOWN_TTL` = 600s | down 更短 |

改写：`downloads.wordpress.org` → 包源（路径保留）；`api.wordpress.org` → 元数据源（查询串保留）；其它主机不改写。镜像不可用则整段不改写。

**3.x 测试名（必须有一一对应的 PHPUnit 测试方法或 `@testdox`）：**

来自 `tests/test-wporg-mirror-fallback.php`：

| 节标题 | 关键断言 |
|--------|----------|
| `== 镜像可用 ==` | 200+octet-stream 可用；206+zip 可用；302 可用 |
| `== 镜像不可用：本次故障的真实形态 ==` | 404+JSON 不可用；504 不可用；404+HTML 不可用 |
| `== 关键：状态码 200 但内容类型不对，也必须判不可用 ==` | 200+JSON 不可用；200+HTML 不可用 |
| `== 传输层失败 ==` | `WP_Error` 不可用 |
| `== 探测路径必须是真实安装包路径 ==` | URL 含 `/plugin/` 且以 `.zip` 结尾；带 Range；标记自身请求 |
| `== 体积校验：…空壳，也必须判不可用 ==` | content-range 14B 不可用；87533B 可用；content-length 14B 不可用；38489B 可用；无体积头不因体积拒绝；1023B 不可用 |
| `== 探测必须打**安装包主机**，不能打元数据主机 ==` | 打 `MIRROR_PACKAGE_ORIGIN`；两源主机不同 |
| `== 改写按来源主机分流：… ==` | 安装包→包源；语言包→包源；update-check→API 源；查询串保留；非 .org 不改写 |
| `== 状态缓存：不能每次请求都去探测 ==` | 三次调用只探测一次 |
| `== 不可用状态同样被缓存，但 TTL 更短以便自动恢复 ==` | `DOWN_TTL < UP_TTL` |

来自 `tests/test-mirror-health-fallback.php`（本任务若只做 wporg，下列与 **admincdn 替换表**相关的节在 PHPUnit 里用「同文件占位 + skip 注明 M1-05」亦可，但 **不得删旧测试**；推荐本任务把 host_of / is_healthy 抽到共享 `Connectivity/MirrorHealth` 供 M1-05 用，则下列节一并搬来）：

| 节标题 | 关键断言 |
|--------|----------|
| `== host_of() 解析 ==` | 裸主机、带路径、带协议、cdnjs、空串、空白 |
| `== 替换表里的真实目标都能解析出预期主机 ==` | 与 `Service/Acceleration.php` 映射表一致的 12 条 |
| `== is_healthy() 语义 ==` | 未知视为健康；up/down；不串主机；空主机健康 |
| `== unhealthy_hosts() ==` | 只列出被标 down 的 |
| `== 探测路径必须是插件实际生成的形态 ==` | 非根路径；cdnjs 不带 `/ajax/libs` 前缀；googleajax 带该前缀；jsd 以 `/npm/` 开头；无 `public.admincdn.com`；wpstatic 含 `wp_version`；ts 为主题截图形态 |

## 与 3.x 的关系

移植：`Service/Super.php` 的 `filter_wordpress_org`、`is_mirror_usable`、`probe_mirror`、`parse_total_bytes`。公共库健康见 `Service/MirrorHealth.php`（`host_of`、`is_healthy`、`probe_targets`、`unhealthy_hosts`）——若本任务抽出共享类，M1-05 复用。

**必须保留的 3.x 断言：** 上述两份 `tests/test-*.php` 原样继续被 `composer test:legacy` 跑过；新 PHPUnit 是改写不是替换。
