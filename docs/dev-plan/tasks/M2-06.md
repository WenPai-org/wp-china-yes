## 行为规格

以 `docs/specs/announcements.md` 与 rewrite-plan §4.2 为准，冲突时以 spec 为准并在报告说明。

**公告：** 源 `GET https://wpcy.com/wp-json/wpcy/v1/announcements`（插件不解析 RSS）。不可加源。transient `wpcy_announcements` 24h；失败留旧缓存；无缓存不渲染、不报错。展示前 5 条未关闭（`published_at` 新到旧）。关闭写入 `wpcy_settings.announcements.dismissed`（最多 100，丢最旧）。未知 id dismiss 仍 200。字段：id, source∈{wptea,one}, title, url HTTPS, summary≤200, published_at。仅概览页。

**NoticeControl：** 规则版本化 JSON，mock 开发。铁律：永不隐藏核心更新、安全、站点健康通知（匹配 core / `update-nag` / Site Health 类钩子则跳过）。被隐藏项诊断页可查：来源插件 / 匹配规则 / 首次隐藏 / 次数。用户不可在 UI 编辑规则。3.x `adblock_rule` CSS 选择器方案不采用。

默认不启用对生产 wpcy.com 的拉取：无有效缓存且未配置 mock URL 时公告区空白。
