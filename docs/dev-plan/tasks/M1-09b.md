## 背景

M1-09 生成了一把测试公钥却没把私钥入仓，导致基线一旦改动就无法重签；v4 下 `new Ruleset()` 验签失败会拿到空主机表。本任务把"可重签"补齐：入仓一对明确标注 TEST ONLY 的 Ed25519 密钥、一个签名脚本、重签基线，并让验签测试不再 skip。
