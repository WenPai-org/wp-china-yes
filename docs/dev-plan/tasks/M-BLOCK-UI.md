# M-BLOCK-UI：本站拦截清单与出站请求三层 — 原型 / 规格需求说明

这份文档**不是任务书**。它给后续 M-UI 任务提供状态清单和文案原文。产品化 UI 必须走 [`docs/dev/design-sop.md`](../../dev/design-sop.md) 门禁：每个状态有 HTML、文案是原文、feibisi 书面认可后才能拆 M-UI 任务写代码。

## 解决什么问题

高级设置里「本站拦截清单」一行及其编辑态、诊断页「出站请求三层」只读卡与「测一条地址」，需要在写代码前冻结状态与词表。本文件把 [决定 A 节](../decisions/2026-09-06-http-block-merge-and-feature-absorption.md) 与 [ADR-005](../../architecture/adr-005-feature-absorption.md) 的界面面列成可画的状态。

## 不做什么

- 不写视觉、不写布局、不定色值与间距（那是原型的事）。
- 不改 `src/`、不改 `src/Admin/app/`、不拆 M-UI 任务书。
- 不发明 §4 词表以外的用户可见句子。
- 不把本文件当成已认可的 UI 任务书（无 `APPROVAL.md` 则 M-UI 任务书无效）。
- 不画正则/通配/路径输入、不画导入导出、不画仪表盘拉黑、不画「配额」。

依据：决定 A1–A6；ADR-005；[`docs/design/admin-ui-spec.md`](../../design/admin-ui-spec.md) §2 两条信息架构、§4 词表；规格编号 `CO-10` / `DG-07`；REST [`docs/specs/rest-api.md`](../../specs/rest-api.md) `GET/PUT /site-blocklist`、`GET /residency/protected`、`POST /residency/test`。

引擎由 [M-BLOCK-1](M-BLOCK-1.md) 交付。本文件假设那份已合，或与原型并行时以 mock 该 REST 为准。设计已在原型 E 的「后台体验」卡预留位置（决定 §三）。

## 1. 设置 → 高级 → 后台体验：本站拦截清单（CO-10）

高级档一行。简单档无此行。网络管理员 / 单站管理员可编辑；多站点子站管理员只读（沿用 CO-06「已由网络设定」，不另造词）。

### 文案（§4 原文）

| 用途 | 原文 |
|------|------|
| 行标题 | 本站拦截清单 |
| 说明 | 只拦截，不改道 |
| 上限 | 最多 20 条 |
| 命中保护主机 | 文派服务不可拦截 |
| 整包开关（若同区展示噪声包） | 噪声拦截包 |

不要写「飞行模式」。不要写 HttpBlock。不要写「白名单」。不要写正则示例。

### 收起态（一行）

| 状态 | 界面要什么 | 数据 |
|------|------------|------|
| 关 | 标题「本站拦截清单」；开关关；说明「只拦截，不改道」不强制出现（正常项可不解释） | `enabled === false` |
| 开且空 | 标题；开关开；可进入编辑 | `enabled === true`，`hosts.length === 0` |
| 开且有条 | 标题；开关开；条数（数字即可，单位词用「最多 20 条」里的「条」） | `hosts.length` 1–20 |
| 只读（子站） | 同开/关，无编辑入口 | 无 `manage_network_options` |
| 恢复模式 | 本行仍显示；运行时引擎不挂钩（不另写「恢复中无效」除非先改词表） | `recovery_mode` |

### 编辑态（列表 + 添加主机）

不写布局（不规定 Modal 还是页内展开）。必须有：当前列表、添加主机、删除一条、保存。

| 状态 | 界面要什么 | 数据 |
|------|------------|------|
| 空列表 | 列表空；添加控件可用；可见「最多 20 条」 | `hosts: []` |
| 有条 | 每行：主机名 + 匹配（exact / suffix 的呈现由原型定，**不得**用英文 `exact` 当唯一标签——若原型需要中文匹配名，先改词表再画；本文件不发明「精确」/「后缀」） | `hosts[]` |
| 添加 | 输入主机名；匹配二选一；可选备注（`note`，不另造标签则原型用输入本身，不新增词） | 未保存 |
| 满 20 | 添加控件不可用；可见「最多 20 条」 | `hosts.length === 20` |
| 命中保护 | 保存失败；红 Notice 原文「文派服务不可拦截」；列表不写入该条 | PUT 400 `wpcy_blocklist_protected_host` |
| schema 失败 | 沿用词表「暂时无法保存设置，请检查填写内容后重试。」 | 400 `wpcy_invalid_schema`（非法主机、21 条） |
| 权限不足 | 沿用「暂时无法访问该内容，请确认你有管理权限。」 | 403 |
| 保存成功 | 沿用「已保存」 | PUT 200 |

`match` 的中文标签本文件不发明。原型若只用主机名、匹配用控件值不展示英文，可以；一旦要写标签，先登记 §4。

噪声拦截包：若高级同区有开关，标签「噪声拦截包」；无条目编辑。关 = `modules.noise_block.enabled=false`。不要列出噪声包主机（那是签名包，诊断三层只读卡可展示）。

## 2. 诊断：出站请求三层（DG-07）

诊断页一张只读卡（与「出站主机记录」DG-04 并列或同 Tab 下一段；布局由原型定）。数据：`GET /residency/protected`。另有「测一条地址」：输入框 + 动作，数据 `POST /residency/test`。

### 文案（§4 原文）

| 用途 | 原文 |
|------|------|
| L0 标记 | 受保护 |
| 测输入/动作 | 测一条地址 |
| （层名若需标题） | 用「本站拦截清单」「噪声拦截包」「受保护」；L1 沿用已有「出站主机记录」语境，不另造「数据驻留」 |

不要展示 URL 查询串。不要展示 IP。不要写「拦截器引擎」。

### 只读卡状态

| 状态 | 界面要什么 | 数据 |
|------|------------|------|
| 加载 | 不写英文 Spinner 文案；空着或沿用 wp-admin 等待 | GET 进行中 |
| 有数据 | 三层列表：L0 主机带「受保护」；L1 档位只读（与 DG-04 不重复细节，本卡只回答「哪一层会动」）；L2 当前本站清单只读；噪声包开/关 + 条目只读 | `l0` / `l1` / `l2` / `noise_block` |
| 空 L2 | L2 区空；不发明「尚未添加」 | `l2.hosts: []` |
| 验签仅内置 | L0 仍列出硬编码主机并标「受保护」 | `l0.source === "builtin"` |
| 错误 | 沿用「暂时无法连接文派服务」句式；不弹出英文 `WP_Error` | GET 403 / 网络失败 |
| 多站点子站 | 只读，无跳去编辑 L2 的网络写入口（可有「本站拦截清单」四字指向设置，若设置对该用户只读则停在只读） | 无网络写权限 |

### 「测一条地址」状态

| 状态 | 界面要什么 | 数据 |
|------|------------|------|
| 空 | 输入框空；按钮/提交「测一条地址」 | 尚未 POST |
| 进行中 | 等待；不展示上一轮结果以免当成本轮 | POST 尚未返回 |
| 结果 L0 | 展示 host +「受保护」（放行语义用词表已有词，不另写「已放行」） | `layer=l0` `action=allow` |
| 结果 L1 | 展示 host + 处置：改道 / 记录 沿用 DG-04「已改道国内」/「记录中」——**「记录中」已在 §3.4 出站主机表，不是本任务新词**；本卡不要新造 |
| 结果拦截 | 展示 host；L2 用「本站拦截清单」；噪声包用「噪声拦截包」 | `layer=l2` 或 `noise_block`，`action=block` |
| 结果未命中 | 不发明「未拦截」。原型可只展示 host、不标层 | `layer=none` |
| 非法 URL | 沿用「暂时无法保存设置，请检查填写内容后重试。」或失败 Notice 句式；不展示 `wpcy_invalid_schema` | 400 |
| 失败 | 琥珀 Notice，用已有「暂时无法…请稍后重试。」模板；本文件不发明新失败句 | 403 / 网络失败 |

测一条不发真实出站请求（引擎保证）。输入框占位符若需要，原型用「测一条地址」本身，不另造「输入 https://…」。

## 3. 原型必须覆盖的画面（供 design-sop 清单）

高级设置：本站拦截清单收起关 / 开空 / 开有条；编辑态空 / 有条 / 满 20；保存命中保护「文派服务不可拦截」；子站只读。

诊断：出站请求三层有数据（L0 标「受保护」）；L2 空；测一条地址空 / 结果 L0 / 结果拦截 / 失败。

每个状态的 HTML 进 `docs/design/prototypes/`，认可进该页 `APPROVAL.md`，再拆 M-UI 任务。M-UI 任务书必须引用本文件、原型路径、认可日期、规格编号 `CO-10` `DG-07`。

设置行注册走 `SettingsRows::register( 'privacy.site_blocklist', array(), array( /* 本站拦截清单 */ ) )`（待 M-UI 实现，见 [`module-authoring.md`](../../dev/module-authoring.md)）。
