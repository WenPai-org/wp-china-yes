### Telemetry 字段（从 `collect_report()` / `get_woocommerce_data()` 抄）

顶层：

| 字段 | 来源 |
|------|------|
| `site_uuid` | `WenPai_Bridge_Site_Identity::get_uuid()` → 4.0 用 `wpcy_site_identity.site_uuid` |
| `site_url` | `home_url()` |
| `wp_version` | `get_bloginfo('version')` |
| `php_version` | `PHP_VERSION` |
| `mysql_version` | `SELECT VERSION()` |
| `is_multisite` | `is_multisite()` |
| `active_theme` | `get_stylesheet()` |
| `locale` | `get_locale()` |
| `server_software` | `$_SERVER['SERVER_SOFTWARE']` sanitize |
| `wpcy_version` | `CHINA_YES_VERSION` |
| `telemetry_version` | 3.x `TELEMETRY_VERSION` 常量值，保持 |
| `plugins[]` | slug, version, active, name, author(去标签), requires_wp, requires_php, network_active |
| `platform` | os, bits, php_memory_limit, php_max_input_vars, php_post_max_size, php_max_execution_time, php_extensions[{name,version}], is_ssl, image_support{webp,avif,heic,jxl}, myisam_tables, users_count, blogs_count |
| `themes[]` | slug, name, version, author, is_active, is_child_theme, parent_slug, is_block_theme |
| `translations[]` | type, slug, language, version（上限 500） |
| `woocommerce` | 仅 WC 激活时存在，否则键不出现 |

`woocommerce`：`wc_version`, `currency`, `base_location`（仅 country）, `is_ssl`, `hpos_enabled`, `allow_tracking`, `products_total`, `products_by_type`, `orders_total`, `orders_by_status`, `gateways[]{id,enabled}`, `shipping_methods[]{id,enabled}`, `user_roles`, `template_overrides`, `block_cart`, `block_checkout`, `calc_taxes`, `coupons_enabled`, `guest_checkout`, `shipping_zones_count`。

禁止出现：订单正文、顾客邮箱、管理员邮箱、许可密钥、精确地理（state/postcode/city）。cron **无条件**调度；忽略任何旧 `telemetry` option。界面不露出。3.x 测试 `tests/test-telemetry.php` / `test-telemetry-woocommerce.php` 的字段与禁字断言必须在新 PHPUnit 中保留。

### DataResidency 基线 ruleset

文档形状见 spec §1。签名 Ed25519，规范化 JSON（键字典序、UTF-8、无多余空白）。公钥可先用测试钥；与 apps 是否共用 **待定（M0，安全/发布）**。

**本任务只实现 `record` 与 `ignore`。`reroute` 分支代码必须存在，但 `enabled_when=ingest_ready` 探测为假时不启用（不改 URL，不得回落到 record，也不得复制后再放行）。**

初始条目（spec §6 + 定稿 §7.1a；`ruleset_version` 发版整数 **待定（M0）**，内置先用 `1` 并在 JSON 注释/文件头标明待冻结）：

**A · reroute + ingest_ready（本任务探测恒假 → 不改写）**

| host | match | target（占位） |
|------|-------|----------------|
| `api.wordpress.org` | exact | `https://api.wenpai.net/`（仅 version-check / plugins/update-check / themes/update-check；路径过滤表达式待定 M0，未定前用路径前缀白名单这三条） |
| `tracking.woocommerce.com` | exact | `https://updates.wenpai.net/ingest/woo-tracker` |
| `pixel.wp.com` | exact | 待定（M0）云桥 Tracks URL，JSON 里 `target` 可空字符串但 action 仍 reroute+ingest_ready |
| `stats.wp.com` | exact | 同上 |
| Jetpack Stats 埋点 | 待定（M0） | 对照现网后补；未补前不要猜主机名，JSON 可省略该条并在报告写「待定」 |

**B · record**

| host | match | data_class |
|------|-------|------------|
| `rest.akismet.com` | suffix | comments |
| Jetpack 连接/模块 API | 待定（M0） | connection；未补前省略 |
| Woo.com helper | 待定（M0） | licensing；未补前省略 |
| Freemius | 待定（M0） | licensing；未补前省略 |
| EDD Software Licensing | 待定（M0） | licensing；未补前省略 |

**C · ignore**

```json
{ "host": "*", "action": "ignore" }
```

B 档只记 `host` / `data_class` / `count` / `last_seen`，**不记正文、不记 URL 查询串**。用户不可加域名。
