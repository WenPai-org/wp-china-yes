## 统筹决定（对审查里的开放点）

- **绑定确认**：`start()` 成功后同一请求内立即尝试 `confirm()`（服务端回站校验通常在秒级完成）；未成功则保持 `pending` 并**登记一次性 cron**（60s 后重试，最多 10 次，之后标 `failed` 可重新发起）。不新增 spec 外的 REST。
- **权益降级接线**：`EntitlementsModule::register()` 挂 `wpcy_entitlement_allows`（参数：service slug）；`Degrade::shouldUseUpstream($service)` 为真时返回 false。受限层服务名固定：`windfonts`、`admincdn`（公共库）、`wpmirror-packages`（安装包镜像）、`motusnap`。基线层模块不查。
- **NoticeControl 铁律实现**：① 规则 `selector`/`class` **白名单校验**——只接受带插件特定前缀的 class/id（正则 `^[a-z0-9-]+$` 且不在 WP 通用集合：`notice`、`notice-*`、`updated`、`error`、`update-nag`、`update-core-*`、`site-health*`、`is-dismissible`、`inline`）；命中通用集合的规则**整条丢弃并记诊断**；② `print_hide_styles()` 只对通过校验的规则输出 CSS；③ `record_hidden()` 只在规则通过校验时计数；④ 新增测试：规则 `class=notice-warning` 不产生任何 CSS、`update-nag` 永不被隐藏。
- **expired**：REST 侧 `data:write`/`data:delete` 对 `expired` 与 `exhausted` 同样拒（`wpcy_apps_entitlement_required`）；前端 `exhausted` 仍挂 iframe（只读由 REST 拦），`expired` 与无权益一样只显示 Modal +「获取」。
- **A1–A9 e2e**：按 `docs/dev-plan/tasks/M1-10.md` 末尾"追加要求"里的九条表实现 `tests/e2e/apps.spec.js`；A4 的 `entry_url` 指向本地 mock 工具页（wp-env 里用 `http://localhost:8888/wp-content/plugins/wp-china-yes/tests/fixtures/mock-app/index.html` 或把 fixture 拷进 uploads——报告写明）；A8 需 `GET /apps` 区分"空目录"与"不可达"（响应加 `index_status: ok|unreachable|invalid`），前端据此显示琥珀提示。
- 采纳的建议（一并做）：缺 key 用 `wpcy_apps_key_invalid` 不用 `unknown_app`；`Mappers::PUBLIC_ASSET_MAP` 只留五项、其它记 `unsupported_whitelist`；`Index`/`Catalog` 远程请求 `timeout<=10`、`sslverify=>true`；`attachBridge` 传真实 `CHINA_YES_VERSION` 与 context；连接页 Windfonts 去掉 `disabled`（绑定后可用由权益决定，不由 UI 写死）、`Catalog` 接进 `Plugin::create()`；`Stylesheet.php` 选择器 escape；`revoke()` 清权益 transient、`refresh()` 非 bound 不出站；`composer.json` `config.process-timeout` 600；`RestModule.php` 过时注释删。
- 不做：4.0 PHPUnit 纳入 PHP 7.4 job（PHP 下限待定，M4 处理）；`AdminModuleTest` 禁词扫描方式（保留）。
