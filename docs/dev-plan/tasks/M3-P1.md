### 公钥

- 文件在 `src/Security/keys/`，随插件发布。同时携带当前与下一把，支持 `kid` 轮换（定稿 §7.5b-3）。
- 禁止把私钥写入本仓。文件头不得复制测试钥的 `TEST ONLY` 到生产钥；测试钥文件头必须仍含 `TEST ONLY`。
- 验签失败：单工具不显示；整份索引丢弃并留上一份缓存。本任务不改该逻辑。

### `enabled_when=ingest_ready`

- 探测 `GET {health}`：200 且 JSON `ready` 为 true 才启用对应 A 档改写。
- 探测频率 **待定（M3 前）**（spec §3 原待定）。未定前沿用模块已有行为（若无缓存，报告写明实际次数，不新增产品策略）。

- `pixel.wp.com` / `stats.wp.com` 的 `target` 仍为空：即使 health `ready`，这两条仍不改写。

## 验收标准

本地 Studio（总计划 §0）。CLI：`~/.studio/bin/studio`。站点：`~/Studio/wpcy-40`。先 `studio start --path ~/Studio/wpcy-40 --skip-browser`。

1. `composer check` 全过；`composer test:legacy` 仍 29 passed。

2. 生产默认值在源码，staging 不在默认值：

```bash
grep -n "license.wenpai.net" wp-china-yes.php src/ -r | head
grep -n "WPCY_SERVICES_API" wp-china-yes.php src/ -r | head
# 期望：默认基座为 https://license.wenpai.net/v1。
grep -n "ingest/health" src/ -r | head
# 期望：生产健康 URL 出现。
grep -n "apps.wpcy.com/index.json" src/ -r | head
```

3. 公钥文件与 kid：

```bash
ls -1 src/Security/keys/
# 期望：至少两把 kid 的当前公钥；下一把若 S1 已交付则同时存在。无私钥、无 .key。
grep -l "TEST ONLY" tests/fixtures/keys/* | sort
# 期望：仅 fixtures。src/Security/keys/ 不含 TEST ONLY（除非 S1 只给了 staging 钥且文件头写明 staging——若发生，报告写明，不得标生产）。
```

4. Studio 对 staging 绑定（常量覆盖方法用 `studio wp --path ~/Studio/wpcy-40 config set` 或等价；以 M2-02 实际常量为准）：

```bash
studio wp --path ~/Studio/wpcy-40 eval 'echo defined("WPCY_SERVICES_API") ? WPCY_SERVICES_API : "undef";'
# 覆盖为 staging 后：
studio wp --path ~/Studio/wpcy-40 wpcy status
# 再触发绑定（WP-CLI 或 REST）；命令以 M2-02 交付为准。
curl -sS "$(studio wp --path ~/Studio/wpcy-40 option get home)/wp-json/wpcy/v1/binding"
# 期望：status=bound，含 site_hash，不含 credential。
curl -sS "$(studio wp --path ~/Studio/wpcy-40 option get home)/wp-json/wpcy/v1/entitlements"
# 期望：含 id=wpcy-leaf-motusnap-100。
```

5. ingest 探测（Studio 能访问 staging 云桥时）：

```bash
curl -sS "$STAGING_BRIDGE/ingest/health"
# 期望：ready true。再在站点上对 tracking.woocommerce.com 发一次 HTTP（eval 或诊断），确认 URL 被改到 staging ingest；再停掉 health（或临时指错误 URL）后不再改写。
# 若 Studio 出网受限：在报告写明，用单元层对 callable=true/false 的既有测试证明接线，不得假称生产已改道。
```

6. 索引真实拉取：

```bash
studio wp --path ~/Studio/wpcy-40 eval '/* 触发 Index 拉取的已有 CLI/REST；以 M2-04 为准 */'
# 或 curl 插件所用 URL。期望：验签通过；失败时不展示未签名工具。
```

7. `git diff --stat` 限于常量文件、`src/Security/keys/`、公钥装入点、探测 URL 接线。不得改 `src/Services/SiteBinding/` 状态机、`src/Privacy/DataResidency/DataResidencyModule.php` 的 record/reroute 算法（构造注入除外）、`framework/`、`Service/`、`client/`、`docs/dev-plan/README.md`。

8. 提交信息前缀 `feat(connect): `。
