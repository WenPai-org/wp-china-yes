## 行为规格

以 `docs/specs/config-schema.md` 为准，冲突时以 spec 为准并在报告说明。四个 option 结构原样如下（实现不得增删顶层键）。

**1. `wpcy_settings`（站点，`autoload=yes`）** 必填：`schema_version`、`connectivity`、`modules`、`diagnostics`、`data_residency`、`announcements`、`apps`、`recovery_mode`。`additionalProperties: false`。

- `schema_version`：integer const 1
- `connectivity.wordpress_org`：`auto` \| `off`，默认 `auto`
- `connectivity.public_assets`：`google_fonts` / `google_ajax` / `cdnjs` / `jsdelivr` / `emoji` 的子集，默认五项全开
- `connectivity.avatar`：`cravatar_cn` \| `cravatar_global` \| `off`，默认 `cravatar_cn`
- `modules.notice_control`：bool，默认 true；`modules.windfonts`：bool，默认 false
- `diagnostics.scheduled_checks`：bool，默认 true
- `data_residency.ruleset_version`：integer ≥ 1，默认 1
- `announcements.dismissed`：string[]，max 100，默认 `[]`
- `apps.disabled`：string[]，默认 `[]`
- `recovery_mode`：bool，默认 false。为 true 时全部 URL 改写关闭、全部可选模块停用（本任务只存标志，改写由后续模块读）

**2. `wpcy_network_settings`**：同 `wpcy_settings`，另加 `allow_site_override`（bool，默认 true）。为 false 时子站不得写入 `wpcy_site_overrides`，已有覆盖被忽略。autoload 随 WP 网络 option 惯例，**待定（M0）**：实现方确认 `update_site_option` 后是否需显式声明（不在本任务拍板）。

**3. `wpcy_site_overrides`**：只允许 `schema_version`、`connectivity`、`modules`。缺省段表示不覆盖。

**4. `wpcy_site_identity`（`autoload=no`）**：`schema_version`、`site_uuid`、`binding{status,site_hash,credential,bound_at,challenge_id}`。`status` ∈ unbound/pending/bound/revoked。`credential` 加密存储规则见 spec §4；本任务实现存取接口，不实现绑定流程（M2-02）。

另：`wpcy_migration_backup` 结构按 spec §5 定义进 Schema，本任务不跑迁移。

**点分路径：** `Repository::get('connectivity.avatar')`、`Repository::set('modules.windfonts', true)`。未知路径丢弃并经 Logger warning，不抛致命。业务代码禁止 `get_option('wpcy_settings')`。

**多站点读取顺序：** 默认 ← 网络 `wpcy_network_settings` ←（仅当 `allow_site_override===true`）本站 `wpcy_site_overrides`。单站无网络 option 时用 `wpcy_settings` + Defaults。

凭据不进导出、Site Health、日志（本任务的 `export()` 若存在必须剥 `binding.credential`）。
