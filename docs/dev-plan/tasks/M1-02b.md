# 任务 M1-02b：让 `WPCY_KERNEL=v4` 路径真正不加载 `framework/`

依赖：M1-02 已合并 `main`。并行组 B（可与 M1-04 / M1-05 / M1-09 同时）。预计 diff ≤ 120 行。基于 `main`，工作分支 `grok/m1-02b`。

## 先读

- `docs/dev-plan/README.md` M1 出口：「`WPCY_KERNEL=v4` 打开时 … 旧 `framework/` 未被加载（用 `get_included_files()` 断言）」。
- M1-02 报告第 6 条（`docs/dev-plan/tasks/M1-02.md` 背景）：Composer `autoload.files` 仍无条件加载 `framework/classes/setup.class.php`，v4 路径因此躲不开旧框架。
- `composer.json` `autoload.files`；`autoload-guard.php`（M1-01）；`wp-china-yes.php` 第 54–66 行（autoload → v4 早退 → 3.x 初始化）。
- `framework/classes/setup.class.php` 文件末尾：加载即执行 `WP_CHINA_YES_Setup::init()`。

## 背景

3.x 的设置框架通过 Composer `files` 在 autoload 时就被拉起。M1-02 的开关放在 autoload 之后，所以 v4 路径仍带着 `framework/`。本任务把这个加载从 Composer 挪到 3.x 显式路径，**3.x 加载顺序与时机不变**（仍在 autoload 之后、`TranslationManager` 之前），v4 路径则完全不碰它。

## 交付物

| 路径 | 改动 |
|------|------|
| `composer.json` | `autoload.files` 移除 `framework/classes/setup.class.php`；保留 `autoload-guard.php`、`helpers.php` |
| `wp-china-yes.php` | 在 v4 早退 `return;` 之后、`// 初始化翻译管理器` 之前加一行 `require_once CHINA_YES_PLUGIN_PATH . 'framework/classes/setup.class.php';` |
| `autoload-guard.php` | 删除为 `setup.class.php` 准备的 `WP_CHINA_YES_Setup` / `WP_CHINA_YES` 空壳（不再需要）；保留 `ABSPATH` / `CHINA_YES_VERSION` 兜底与 PHPStan 处理 |
| `tests/Unit/Core/KernelSwitchTest.php` | 新增用例：模拟 v4 路径引导后，`get_included_files()` 中不含 `framework/`（可在测试里直接 `require` 相关文件并断言；若纯单元不可行，改为 `tests/wordpress-smoke.sh` 追加一条 `wp eval` 断言并在报告说明） |
| `tests/wordpress-smoke.sh` | 追加：`WPCY_KERNEL` 未定义时 `class_exists('WP_CHINA_YES_Setup')` 为真（3.x 路径仍加载框架）；定义 `v4` 时（用 `--exec` 或 `wp eval` 前 `define`）`get_included_files()` 不含 `framework/`。若 wp-env 里无法在 eval 前定义常量，写明并只保留第一条 |
| `composer.lock` | `composer dump-autoload` / `composer update --lock` 后的结果 |

## 行为规格

- 3.x（常量未定义）：`setup.class.php` 仍在 autoload 之后、任何 `Service/*` 之前被加载一次；`WP_CHINA_YES_Setup::init()` 仍在同一时机执行。设置页、26 个 section、AJAX 保存行为不变。
- v4：`get_included_files()` 不含任何 `framework/` 路径；`class_exists('WP_CHINA_YES_Setup', false)` 为假。
- `helpers.php` 两条路径都需要，保持在 `files`。

## 禁区

- 不改 `framework/` 内任何文件；不改 `Service/`、`client/`、`Plugin.php`、`templates/`。
- 不改 M1-02 的 `src/Core/*`。
- 不删 `autoload-guard.php`（helpers.php 在 CLI 下仍需要它）。
- 总计划 §0 不变量。
