## 背景

4.0 受限免费层的前提是自动匿名绑定：一个 `site_hash` 一条权益，无用户账号。第一条真实权益是 MotuSnap。小工具索引与驻留主机表的生产签名也落在本服务（内部接口），私钥不落人手、不进插件仓。

插件在 M2 对 mock 开发；本任务让 staging 能走通挑战，供 **M3-P1** 在 Studio 对接。生产对公网只暴露绑定 / 权益合同表；签名服务不对公网。

## 交付物

全部落在 `WenPai-org/license-server`（及该仓文档 / fixtures）。本产品仓零服务端代码。

| 交付 | 职责 |
|------|------|
| 绑定端点（现有路由内） | `POST /v1/site-connections`、`POST /v1/site-connections/{challenge_id}/confirm`；撤销路径见行为规格 |
| 权益端点 | `GET /v1/sites/{site_hash}/entitlements` |
| MotuSnap 权益类型 | id `wpcy-leaf-motusnap-100`：每月 100、仅已绑定站点 |
| 内部签名服务 | 两个 `kid`：`wpcy-apps-2026`、`wpcy-ruleset-2026`；当前与下一把公钥可同时公布 |
| OpenAPI 草案 | 该仓文档内；覆盖上表公网端点与错误码，**不含**签名服务的公网路径 |
| 合同 fixtures | JSON 样例：挑战请求/响应、回站拉取、confirm、权益四态 |
| staging 挑战脚本 | 一条 `curl` 走通 ①→③→④（对 staging，不打生产） |

公钥随插件发布在 `src/Security/keys/*.pub` 是 **M3-P1** 的事；本任务只在 license-server / devops secrets 生成并保管私钥，并把**当前 + 下一把**公钥交给 P1。

## 行为规格

以 `docs/specs/entitlements.md` 为准，冲突时以该 spec 为准并在报告说明。空白不拍板，标「待定（M3 前）」。

### 端点表（摘 spec）

基座：`https://license.wenpai.net/v1`（定稿 §7.5b-2）。插件常量名 `WPCY_SERVICES_API`。staging 基座 URL **待定（M3 前）**，由本任务报告给出，供 P1 验收覆盖，不得把 staging 写进插件生产默认值。

| 方法 | 路径 | 谁调 | 说明 |
|------|------|------|------|
| POST | `/v1/site-connections` | 插件 | 发起挑战。写请求带 `Idempotency-Key` |
| GET | `{site_url}/wp-json/wpcy/v1/binding/challenge?id={challenge_id}` | **本服务回站拉取** | 在用户站点上，不在 license-server。公开只读 |
| POST | `/v1/site-connections/{challenge_id}/confirm` | 插件 | 取回 `{ site_hash, credential }` |
| GET | `/v1/sites/{site_hash}/entitlements` | 插件 | 权益列表。认证如何附带 `credential` **待定（M3 前）**：Authorization 头或签名查询，由本仓给出后写入 OpenAPI；未定前 staging 可用文档化的测试头，并在报告写明 |
| DELETE | 撤销 | 插件通知本服务 | 路径 **待定（M3 前）**（spec 问是否复用 `DELETE /v1/sites/{site_id}/connection`）。未定前 OpenAPI 标 `undocumented`，**不要猜 CDN 合同路径** |

时间一律 UTC ISO 8601。错误 `code` 稳定；插件按 code 分支。插件已冻结的码：`wpcy_binding_not_pending`、`wpcy_apps_entitlement_required`、`wpcy_apps_quota_exceeded`。本服务自身失败码表 **待定（M3 前）**；若用不同字符串，适配层译成 `wpcy_` 前缀。

### 挑战流程时序

```
插件                         license-server (S1)                 用户站点 WP
  |                                  |                                |
  | ① POST /v1/site-connections      |                                |
  |   {site_url, site_uuid,          |                                |
  |    plugin_version}               |                                |
  |<-- {challenge_id,                |                                |
  |     challenge_token, expires_at} |                                |
  | 本地 status=pending              |                                |
  |                                  | ③ GET /wp-json/wpcy/v1/        |
  |                                  |    binding/challenge?id=…      |
  |                                  |------------------------------->|
  |                                  |<-- {challenge_token}           |
  |                                  |    （仅 pending 且未过期；      |
  |                                  |     否则 404 /                 |
  |                                  |     wpcy_binding_not_pending）  |
  |                                  | 校验 token，签发               |
  |                                  | site_hash + credential         |
  | ④ POST /v1/site-connections/     |                                |
  |    {challenge_id}/confirm        |                                |
  |<-- {site_hash, credential}       |                                |
  | ⑤ status=bound                   |                                |
```

同站重装 / 换管理员不叠额（同一 `site_uuid` 回到同一 `site_hash`）。换域名重新挑战。`site_uuid` 由插件生成并稳定存放；本服务不生成、不改写。

授权键是 `site_hash`，**不按域名授权**。

### 权益查询

响应形状（摘 spec）：

```json
{
  "entitlements": [
    {
      "id": "wpcy-leaf-motusnap-100",
      "service": "motusnap",
      "tier": "limited-free",
      "status": "active",
      "quota": {
        "limit": 100,
        "used": 12,
        "period": "month",
        "resets_at": "2026-10-01T00:00:00Z"
      }
    }
  ]
}
```

`status` ∈ `active` | `exhausted` | `expired`。额度数字是服务端事实；插件不写死 `100`。

未绑定（无有效 `site_hash`）不得返回 MotuSnap 权益。绑定撤销后该站权益立即不可用。

### MotuSnap

- 权益 id：`wpcy-leaf-motusnap-100`
- 每月 100 次，只截已绑定站点自己的页面
- MotuSnap 服务端校验时向本服务查，不自建第二套身份（定稿 §7.5b-2）

### 内部签名服务

- **不对公网**。不进 OpenAPI 的 public paths；不配公网 DNS；只允许 feicode-prod 回环 / 内网 / 已有内部鉴权。
- 两个 `kid`：`wpcy-apps-2026`（小工具 manifest / `index.json`）、`wpcy-ruleset-2026`（驻留主机表）。载荷带 `kid`。
- 规范化规则与 `docs/specs/apps-manifest-and-bridge.md` §1.3 相同。
- **kid 轮换**：同时公布当前与下一把公钥；验签方（插件）按 `kid` 选钥；旧钥在下一把启用前不得删除。私钥只在 feicode-prod secrets（devops），不落人手、不进 git。
- 密钥生成是安全动作，不由开发机代理执行（定稿 §7.5b-3）。本任务可调用已有签发入口，但不得把私钥写入仓库或日志。

### 不存的东西

不存用户账号、密码。绑定是匿名站点挑战，无登录。凭据可存本服务侧的站点记录，但不得在日志、admin 列表、导出里出现明文 `credential` / `challenge_token`。
