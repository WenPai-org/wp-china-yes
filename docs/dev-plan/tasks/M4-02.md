## 背景

删旧后 3.x 类不在包内。升级靠 `Migration\Runner` 读仍留在库里的 `wp_china_yes`。影响分析：首次启动接线是 M4-01 的活；本任务证明矩阵每一行在真实 WordPress 上成立，且装回 3.9.3 后旧 option **未被破坏**。

## 行为规格

装回用的 3.9.3 必须是 **发行 ZIP**（`docs/release/3.9.3-runbook.md` 产物或 GitHub Release 附件），不得用 4.0 `main` 工作树冒充。3.9.3 尚未放行：**停下来在报告写明阻塞**，不要用源码包继续。

预置 option：把 `tests/fixtures/legacy-options/*.json` 的 `wp_china_yes` 对象写入对应作用域（单站 `option`，网络 `site_option`）。外层 `_fixture` 不写入数据库。

每条矩阵执行顺序：

1. 干净站，装 3.9.3 ZIP，启用，写入该样本（或损坏/超大载荷）。
2. `wp wpcy migrate --dry-run --format=json`（若 3.9.3 无此命令：先换成 4.0 再 dry-run，报告写明顺序）。
3. 换成 4.0（M4-01 之后的包）：启用。断言首次启动或显式 `wp wpcy migrate` 已写 `wpcy_settings` 或 `wpcy_network_settings`，且通过 schema；`wp_china_yes` 仍在且内容未改。
4. 停用 4.0。
5. 装回 3.9.3 ZIP，启用。断言 `wp_china_yes` 与步骤 1 写入的键/哈希一致；3.9.x 后台可打开（允许无 4.0 菜单）。
6. 4.0 option 允许仍留在库里。

`wp wpcy migrate --rollback` 只还原 4.0 option，**不得**把 4.0 结构写入 `wp_china_yes`。装回 3.9.x 不依赖该 rollback。

Studio 命令示例（路径按 §0，不要用 `~/.local/bin/studio`）：

```bash
studio start --path ~/Studio/wpcy-40 --skip-browser
studio wp --path ~/Studio/wpcy-40 plugin install /path/to/wp-china-yes.3.9.3.zip --force --activate
studio wp --path ~/Studio/wpcy-40 option update wp_china_yes --format=json < tests/fixtures/legacy-options/single-3.8-02.json
# 换 4.0 包后：
studio wp --path ~/Studio/wpcy-40 wpcy migrate --dry-run --format=json
studio wp --path ~/Studio/wpcy-40 option get wp_china_yes --format=json
studio wp --path ~/Studio/wpcy-40 option get wpcy_settings --format=json
studio wp --path ~/Studio/wpcy-40 option get wpcy_migration_backup --format=json
```

多站点用 `~/Studio/wpcy-40-ms` 与 `site option`。

## 与 3.x 的关系

3.9.x 不读 4.0 option。4.0 不写 `wp_china_yes`。本任务证明这条契约在删旧之后仍成立。

## 验收标准

1. 验证报告存在，**八行矩阵每行**贴：预置命令、dry-run 摘要（kept/ignored 计数或键名）、执行后 `wpcy_settings` 或 `wpcy_network_settings` 非空且无 Fatal、`wp_china_yes` 在 4.0 启用后仍在、装回 3.9.3 后 option 键集合或哈希与预置一致。
2. D1：启用 4.0 的 `wp eval` / 前台请求退出码 0，无 PHP Fatal。
3. D2：贴 option 体积（`strlen` 或 `wp option get` 字节）与结果。
4. `composer check` 若改了 PHP 仍须全过；只出报告未改代码则写明。
5. 提交信息前缀 `docs(verify): `（纯报告）或 `fix(migration): `（修了代码）。
6. `git diff --stat` 不含 `docs/dev-plan/README.md`、不含 fixtures JSON 数据。
