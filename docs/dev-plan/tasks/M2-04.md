## 行为规格

以 `docs/specs/apps-manifest-and-bridge.md` 为准，冲突时以 spec 为准并在报告说明。

**测试密钥生成（执行者在本机运行，密钥仅测试）：**

```bash
php -r '
$kp = sodium_crypto_sign_keypair();
$sk = sodium_crypto_sign_secretkey($kp);
$pk = sodium_crypto_sign_publickey($kp);
file_put_contents("tests/fixtures/keys/wpcy-test-ed25519.key",
  "# TEST ONLY\n" . base64_encode($sk) . "\n");
file_put_contents("tests/fixtures/keys/wpcy-test-ed25519.pub",
  "# TEST ONLY\n" . base64_encode($pk) . "\n");
'
```

文件头必须含 `TEST ONLY`。禁止把生产私钥写入仓。

**规范化 JSON（spec §1.3）：**

1. 去掉 `signature` 后对象；
2. 键按字典序递归排序；
3. UTF-8；
4. 无多余空白（RFC 8259 最短序列化）；
5. 对该字节做 Ed25519 分离签名，Base64 写入 `signature`。

验签：`sodium_crypto_sign_verify_detached`。失败则该工具不显示；索引级失败整份丢弃、留上一份缓存。来源主机后缀 ∈ `.wpcy.com` / `.wenpai.net`，HTTPS。默认不拉生产 `apps.wpcy.com`；测试指向 fixtures。

**REST（摘 spec §4）：**

| 方法 | 路径 | 额外 permission |
|------|------|-----------------|
| GET | `/apps` | — |
| GET | `/apps/{id}/context` | `site:read` |
| GET | `/apps/{id}/data` | `data:read` |
| GET | `/apps/{id}/data/{key}` | `data:read` |
| PUT | `/apps/{id}/data/{key}` | `data:write`，body ≤ 64KB |
| DELETE | `/apps/{id}/data/{key}` | `data:delete` |
| GET | `/apps/{id}/entitlement` | `entitlement:read`（本任务可返回 mock 空/挂钩 M2-03 若已合并；并行组 E 可能尚未有 Entitlements——用可注入的 Entitlements 接口，缺省 exhausted） |
| POST | `/apps/{id}/go` | `go:open` → `{url: https://wpcy.com/go/{go_service}?utm_source=wpcy-plugin&utm_medium=app&utm_campaign={id}}` |

`{key}`：`^[a-z0-9_.-]{1,64}$`，否则 `wpcy_apps_key_invalid`。总 key 数 / 5MB **待定（M0）**；单条 64KB 已定。

**错误码表（摘 spec §5）：**

| code | HTTP | 何时 |
|------|------|------|
| `wpcy_apps_unknown_app` | 404 | id 不在已验签列表 |
| `wpcy_apps_signature_invalid` | 400 | 验签失败（索引级记日志） |
| `wpcy_apps_forbidden_permission` | 403 | 未声明 permission |
| `wpcy_apps_entitlement_required` | 403 | paid 无权益 |
| `wpcy_apps_quota_exceeded` | 403 | exhausted 且需配额 |
| `wpcy_apps_key_invalid` | 400 | key 不符 |
| `wpcy_apps_payload_too_large` | 413 | > 64KB |
| `wpcy_apps_origin_mismatch` | 403 | 本任务 REST 层可不发此码（属桥接）；预留常量 |

iframe `sandbox` 不含 `allow-same-origin`。工具拿不到 REST nonce。
