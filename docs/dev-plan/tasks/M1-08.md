## 行为规格

以 `docs/design/admin-ui-spec.md` §2、§3.1、§3.2、§3.4 为准，冲突时以该 spec 为准并在报告说明。原型缺失时以本规格为准。

**信息架构（§2）**

```
文派叶子
├── 概览        ?page=wpcy
├── 连接优化    ?page=wpcy-connect
├── 文派服务    ?page=wpcy-services   ← 本任务占位
└── 诊断        ?page=wpcy-diagnose
    (恢复模式)  ?page=wpcy-recovery   ← PHP，不在本应用
```

命令面板：打开概览 / 连接优化 / 文派服务 / 运行连接诊断 / 进入恢复模式。

骨架：`<Page>` 顶栏 = 标题 + 右侧一个主动作；无自建左侧导航；内容最大宽 1080px。

**组件选型（ADR-002，不得违反）：**

| 用途 | 包 |
|------|-----|
| 控件 | `@wordpress/components` |
| 状态 | `@wordpress/data` store `wpcy/admin` |
| 请求 | `@wordpress/api-fetch` |
| 列表 | `@wordpress/dataviews`（从 `@wordpress/dataviews/wp` 导入） |
| 设置表单 | DataForm |
| 布局 | `@wordpress/admin-ui` `<Page>` |
| 命令 | `@wordpress/commands` |
| **不用** | `@wordpress/interface`；第三方 UI 库；Tailwind；直接 `fetch` |

**概览 §3.1：** 恢复横幅（仅 `recovery_mode`）；三张线路卡；需要处理（最多 5，无则整段不渲染）；公告占位（无数据不渲染）。空状态「尚未检查」+「立即检查」。

**连接优化 §3.2：** 一个 DataForm 四组：`wordpress_org` RadioControl 自动/关闭；`public_assets[]` Checkbox；`avatar` RadioControl 三档；`modules.windfonts` Toggle（未绑定提示可静态文案「绑定后可用配额」并禁用——绑定状态本任务若无 REST 则整组按 schema 默认展示，不发明套餐判断）。保存走 `PUT /settings`。

**诊断 §3.4：** 顶栏「立即检查」→ `POST /diagnostics/run`。四 Tab：连接检查（本任务必须有数据）；被隐藏的通知、出站主机记录、数据与恢复——后三 Tab 可空表 + 说明文案，入口「进入恢复模式」链到 `?page=wpcy-recovery`。

**词表 §4：** 用户可见文案用「兼容性报告」「权益」「配额」；禁用词以 `docs/design/admin-ui-spec.md` §4 表为准（本任务书禁区再列反例，此处不重复）。

体积：首屏 bundle ≤ 300KB gz。键盘可达。

## 与 3.x 的关系

- 不移植 `framework/`、`Service/Setting.php`、欢迎营销区、section 选择器。
- 不保留隐藏 section。legacy 29 必过。

## 追加要求（2026-09-04）

- **普通后台页硬约束（ADR-002 新增，源码依据 linuxjoy docs/research/2026-09-04-openstation-analysis.md E.1）**：不自建全屏壳、不读 `#wpadminbar` 高度、不写死 `top:32px`、页内切换只用 hash 不 `pushState` 改 `?page=`、不访问 `window.top`、命令面板经 `@wordpress/commands` 注册且若 `wp.os?.registerCommand` 存在则额外注册（feature detect）。验收加一条：把应用嵌进一个模拟 chromeless 的 iframe（无 admin bar、`--wp-admin--admin-bar--height:0`）后布局不破。

## 禁区

- 总计划 §0；不改 3.x 运行时。
- 不用 `@wordpress/interface`。不在前端判断套餐。
- 文派服务页本任务不做绑定/小工具容器。
- 禁止「遥测开关」、opt-in、「默认关闭」设置项或文案（反例）。
- 商业链接一律 `https://wpcy.com/go/…`。
- 不手改品牌 token 源 JSON。
