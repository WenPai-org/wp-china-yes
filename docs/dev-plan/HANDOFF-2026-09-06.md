## 1. 今天定下的产品决定（都已写进文档，别再重议）

全部在产品仓 `docs/dev-plan/decisions/` 与 linuxjoy `docs/plans/2026-09-03-wpcy-revamp.md` §7.1c / §7.1d：

1. **3.9.3 撤回**，不做 3.9.4；3.8 → 4.0 直升是主线（M4-02 矩阵已按此跑通）。4.0 **PHP 下限 8.0**。
2. **站点场景**（`domestic` / `crossborder` / `mixed`）+ **每项连通性功能带作用域**（后台/前台）是 4.0 首发必需项（ADR-004；`decisions/2026-09-06-site-profile-and-scope.md` 含 D1–D5 与三节补充/拍板）。
3. **商业模型**：连通性全部免费无配额；叶子是**接入客户端 + 分发渠道**，不卖功能；商业内容露出条件由服务端规则下发，`domestic` 几乎不露出；付费在 wei-* 与文派服务层；后台静态加速 `admin_assets` 维持 **4.1** 且不商业化。Windfonts 等限流由各平台自己做。
4. **HTTP Block 并入**：三层 L0 受保护主机（签名下发 + 硬编码）/ L1 驻留表 / L2 本站拦截清单（只 block、exact/suffix、≤20 条）；**不设高级档**；不新起 `HttpBlock` 品牌；后续所有过往插件按 **ADR-005 四步流程**（分析 → 决定 → 规格 → 实现）模块化并入（`decisions/2026-09-06-http-block-merge-and-feature-absorption.md`）。
5. **数据驻留 × 场景**：方案 A + 保险（A 档改道只在 `domestic`；用户自称国内站即使 geo 在海外也改道）。WP-CLI 视为 admin，WP-Cron 视为 frontend。
6. **头像只留 Cravatar**（中国线路 cravatar.cn / 国际线路 cravatar.com / 关闭），WeAvatar 移除（M-SCOPE-1c 在做）。
7. **插件内不用 WPCY 品牌色**：主色沿用 3.8 的 `#3858e9`，状态色用 WordPress 语义色，灰阶用 wp-admin 灰阶。
8. **设计门禁与验收 SOP** 已落地（产品仓 `docs/dev/design-sop.md`、`task-book-template.md`（DoD 七项）、`acceptance-sop.md`（四层）、`copy-guidelines.md`、`agent-common-rules.md`；`tests/visual/` `npm run visual`）。**UI 代码冻结到原型定稿**。
