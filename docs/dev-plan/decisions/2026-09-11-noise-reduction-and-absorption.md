# 决定：后台净化（去广告 + HTTP Block）与 3.x 功能吸收队列终表

日期：2026-09-11。决定人：feibisi。依据：R-LEGACY-0 盘点报告（linuxjoy `docs/research/2026-09-11-wpcy-3x-feature-inventory.md`）。关联 ADR-005、HTTP Block 决定（2026-09-06）。

## 1. 后台净化统一框架（两层，一个产品概念）

| 层 | 手段 | 清单来源 | 用户配置 |
|----|------|---------|---------|
| 请求层（HTTP Block，已实现） | `pre_http_request` 拦截：L0 受保护主机（签名下发）/ L1 驻留表 / L2 本站拦截清单（≤20，exact/suffix） | L0/L1 签名下发；L2 用户手填 | L2 可填，≤20 条 |
| 元素层（去广告，本决定新增） | wp-admin DOM 隐藏：CSS 选择器规则集输出 `display:none` | **签名规则集由文派服务端维护下发**（按目标插件/元素分组，带版本，自动更新） | 零配置；总开关默认开、可关 |

**边界（硬规则）**：
- 元素层只作用于 wp-admin，不碰前台
- 核心更新、安全、站点健康通知**永不隐藏**（DG-03 既有）
- 3.x 手写 CSS 选择器（`adblock_rule`）**不迁移**；规则能力由远端规则集替代（`replaced_by_remote`）
- 服务端不可达时沿用最近一份规则集，缓存 ≤72 小时（对齐 P4），界面标注更新时间
- 推荐清单容错同口径（决定 E）

## 2. 界面落点

- 设置 → 后台体验：「隐藏后台的推广与广告」开关（默认开）+ 规则集版本/命中数说明
- 诊断 → 出站主机记录卡：元素隐藏本月命中数 + 规则集版本
- 升级说明点名：3.x 开着 Adblock 且手写了选择器的站点，选择器丢弃；`notice_block=on` 的站点核心/安全通知会恢复显示（属纠正）

## 3. 3.x 功能吸收队列终表（feibisi 拍板）

| 事项 | 决定 |
|------|------|
| P3 插件/主题目录截图镜像（sworg） | **作为文派基础服务默认提供**，并入镜像能力，无用户开关 |
| P2 评论增强六项（Comments.php） | **剔除废弃**，4.0 不吸收，Comments.php 不迁入 4.0 代码库 |
| 元素隐藏（原 P1） | **做**，按本决定 §1（签名规则集，用户零配置） |
| 前后台语言分离强制前台/自动检测 | 废弃（与"后台语言跟随管理员"及"不改写"口径冲突） |
| 其余（产品壳 radio、白标、维护模式、页脚监控、排印/RTL、开发库加速、版本号工具、安全常量、CSF 整表备份） | 废弃；升级沟通按 R-LEGACY-0 报告 §4 的发布说明表执行 |

升级发布说明必须点名的 5 项（详见 R-LEGACY-0 报告 §4）：WeAvatar→Cravatar、手写广告选择器丢弃、`notice_block` 用户核心通知恢复、飞行模式自填域名不进 L2、`windfonts=optimize` 档取消。

## 补充（同日）：后台静态加速取消

- **CO-14（后台加速 admin_assets）整体作废**，4.0 不做、4.1 也不再排期。理由（feibisi）：合并/压缩后台静态资源容易导致用户后台界面样式与脚本问题，收益抵不过故障面。
- 3.x 用户若开过后台静态加速：升级后该行为停止，后台资源直接本站加载；列入发布说明点名（替代 R-LEGACY-0 报告 §4 中"意图保留到 4.1"的旧口径）。
- 界面：设置页移除"后台加速"字段（原型已同步）；诊断迁移记录中归入"已不再需要"。
