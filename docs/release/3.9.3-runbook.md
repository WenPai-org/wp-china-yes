## 2. 合并

`codex/wpcy-3.9.3-stabilization` → `master`。

1. 开 PR（目标 `master`，源 stabilization）。描述附 CI 链接与 §7.2 五项对照。

3. **产品放行**（feibisi）后再点 Merge。代理不自行 merge、不直接 push `master`。

## 3. 打包

CI `package` job 产出 ZIP。

```bash
# 在合并后的 master HEAD 上等 package job
# 下载 artifact 名 wp-china-yes-release → dist/wp-china-yes-3.9.3.zip
shasum -a 256 wp-china-yes-3.9.3.zip
# 与 CI 日志中的校验或 artifact 附带摘要比对，必须一致
unzip -tq wp-china-yes-3.9.3.zip
unzip -Z1 wp-china-yes-3.9.3.zip | grep -E '\.git|tests/|docs/' && echo FAIL || echo OK_no_git_tests_docs
```

判据：ZIP 内**不含** `.git`、`tests/`、`docs/`。SHA-256 与该 HEAD 的 CI 日志一致。旧候选 SHA 作废。

## 6. 更新通道

后端（§7.5b-1 定稿）：

`wenpaiorg-prod:/www/wwwroot/wenpai-org/wp-content/plugins/plat-api/API/ChinaYes/VersionCheck.php`

自研插件「对外 API」，硬编码 version + `dl1.weixiaoduo.com` 包地址。`https://api.wenpai.net/china-yes/version-check` 走该文件（阿里 CDN）。

步骤：

1. 先 `cp` 备份，文件名带时间戳，例如 `VersionCheck.php.bak-20260904T120000Z`。
2. 改字段：
   - `version` → `3.9.3`
   - `download_url` → `https://dl1.weixiaoduo.com/2026/09/wp-china-yes.3.9.3.zip`
   - `tested` → `7.0`
   - `requires_php` → `7.4`
   - `last_updated` → 发版日真实时间
   - `requires` 保持 `4.9`（3.x 下限不变）
3. **删除** `rating`、`num_ratings`、`downloaded`、`active_installs` 四个假值（或改为云桥真实数——若当天拿不到真实数则删除，不要留糊弄值）。
4. `php -l VersionCheck.php`
5. `curl -sS https://api.wenpai.net/china-yes/version-check` 核返回 JSON：`version` 为 `3.9.3`，`download_url` 新路径，`tested` 7.0，`requires_php` 7.4，无四个假值键（或为真实数）。

**阿里 CDN 缓存：** 该域在 Tengine/kunlun 之后，可能需要刷新或等待 TTL。若 curl 仍返回 3.8，先查响应头年龄 / `X-Cache`，再请 devops 刷 CDN，不要反复改 PHP 当缓存没刷新。

**`plat-api` 是否受 git 管理待核。** 若不受管理：把改动**前**与**后**的 `VersionCheck.php` 都存进本仓 `docs/release/artifacts/`（文件名含时间戳；**不含密钥**、不含数据库密码）。若受 git 管理：在对应仓按该仓流程提交，本插件仓只记路径与 commit 哈希。

4.0 **不再走 plat-api**；本步只服务 3.9.3。

生产机操作前走主机进入规程（`host-enter wenpaiorg-prod`），只改上述文件。

## 7. 验证

一台 **3.8** 测试站：

```bash
wp plugin update wp-china-yes
wp plugin get wp-china-yes --field=version   # 3.9.3
wp option get wp_china_yes                   # 结构完整（仍是 3.x 数组，不得被写成 4.0 键）
```

后台四处（设置页、仪表盘、插件列表、前台一次）无 PHP 错误 / Warning。

云桥 `_telemetry`：**24h 内**出现该站报文，含 `php_version` 与（若该站有 WooCommerce）`woocommerce`。无 Woo 则不应出现 `woocommerce` 键。隔离站即可，不要用未授权生产客户站。
