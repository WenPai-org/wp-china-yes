# 统计口径表（v1 草案 · 2026-09-11）

> 规则：失败/超时不得计入"已处理"；任何界面数字必须能在本表找到口径；口径变更走本文修订。
> 对应验收规则：空数据或失败状态不得绘制"已接通"类断言（SH-05、M-UI-1b 审查项复用）。

| 界面词 | 口径 | 数据源 | 备注 |
|--------|------|--------|------|
| 更新与安装包 n 次 | 7 天滚动内经叶子完成的 wp.org 更新检查与包下载请求成功数 | `/stats` 本地计数 | 失败/回退期间直连的成功数计入，且事件流标注 |
| 公共库请求 n 次 | 被改写到 adminCDN 节点的资源请求数（含缓存命中的改写请求） | 本地计数 | 按场景区分前后台口径（后台公共库请求） |
| 头像请求 n 次 | 改写到 Cravatar 的头像请求数 | 本地计数 | 仅统计 `get_avatar_url` 命中（M-STATS 口径） |
| 节省下载约 X GB | 镜像下载成功的更新包字节累计 | 计数字节 | 直连回退期间不累计 |
| 后台心跳已节省 n 次 | 被节流抑制的心跳请求数（估算） | 计数 | |
| 出站请求已屏蔽 n 次 | 被仪表盘屏蔽/L2 拦截的出站请求数 | 计数 | |
| 线路延迟 ms | 服务端探测 3 次平均值，每 10 分钟 | route checks | 多上游取最差状态展示 |
| 浏览器测速 | 管理员浏览器单次实测，不做平均；原始源与接通后成对呈现 | `/diagnostics/client-probe` | 对照卡/转换图标数据源 |
| 中国可达性检测 | 大陆探测点全站可达性与最慢耗时（内贸场景） | 文派服务 | 规划中，随 inbound 场景实现 |
