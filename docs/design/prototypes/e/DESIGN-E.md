状态：2026-09-06 产品负责人认可方向（"设置页面的感觉对的"）；同日夜 v5.2 统筹全页审查修正（见 §5 各节"硬规则"），**作为 M-UI 实现的定稿基线**。本文件是原型 `E/` 的规范来源，也是后续 React 实现（M-UI）与视觉验收（`docs/dev/acceptance-sop.md` 第 2 层）的对照依据。原型 14 页由 `E/build.py` 生成；改规格先改本文与 `e.css`，再重新生成，改完立刻 `git commit`（2026-09-06 曾因未提交的源文件被旧版覆盖，导致页面样式整体丢失）。

## 0. 设计立场

1. **叶子在后台里是基础设施，不是应用。** 装上就该少打扰：国内站的界面越少越好；跨境站才需要控制台感。同一套组件，两种密度，由"站点场景"决定。
2. **说价值，不说配置。** 概览回答"它为我做了什么"（次数、节省、事件），配置状态留给设置页。
3. **每个界面只有一个下一步。** 概览最多一条"下一步"提示；卡片最多一个主动作。
4. **和 WordPress 后台放在一起不违和。** 用 wp-admin 的灰阶与系统字体栈；品牌只出现在图标块与主色。
5. **一根侧栏就够。** 插件内导航用页头下的横向标签，不再在 WordPress 左菜单旁再立一根。

## 5. 页面

### 5.1 概览（概览型模板；两种密度）— v5，feibisi 2026-09-06 定

结构取自方向 F，配色与 token 全部沿用 E（不使用品牌色）。自上而下五段，节间距 32px：

1. **可折叠白色 Hero** `.card.hero-w`：展开态**无摘要栏**，右上角一个 28px 幽灵按钮"收起"；收起态是一条 56px 摘要栏（状态 pill + 三个关键事实、竖线分隔 + 右侧主色"展开"）。折叠状态实现时记在 user meta（原型用 localStorage）。展开体两栏：左 eyebrow（11px 字距 .1em 大写灰）→ 30/600 两行标语 → 14px 说明 → 主按钮 + 次按钮；右 160px 健康环（conic-gradient，语义绿 `#00a32a` 对 `#f0f0f1`，中央 34px 数字 + 小标签）+ 三个关键数字。折叠状态由用户记住（实现：user meta）。
2. （仅有事项时）**下一步条** `.next`，一条。
3. **过去 7 天为你处理**：大写小节标题；三张 `.card.stat-a`（图标 + 标签 / 32px 数字 + 单位 + 绿色增长角标 / 说明 / 44px 面积图，面积图用主色 `#3858e9`）。
4. **状态与动态** `.grid2-w`（1.15 : 1）：左 `.routes` 线路列表（10px 光晕圆点 + 名称/说明 + 等宽延迟 + 时间）；右 `.tl` 时间线（连线 + 圆点 + 11px 字距时间 + 事件 + 说明）。跨境站左边换成"从你的浏览器测速"。
5. **来自文派** `.resources2`（次表面，v5.1 精简）：左 220px 标题 + 一句话；右侧按组一行：11px 大写组标签（文派开源 / 学习与支持 / 文派茶馆；跨境加 跨境店工具）+ 30px 圆角小标签链接（14px 图标 + 短名），每组 3–4 个。不再有说明段与三列长文。

**硬规则（v5.2 审查后定）**

- **一页只有一个主按钮。** 有"下一步"条时，Hero 里的按钮全部用次级；没有"下一步"条时 Hero 的第一个按钮可以是主按钮。
- **健康环必须与线路列表一致，两种场景同一口径。** 环 = 服务器侧诊断目标（`GET /diagnostics` 的 `targets`）里 `ok` 的数量 / 总数：全部 `ok` 显示 `100`、标签"线路健康"；有 `fallback` 显示 `正常数/总数`（如 `3/4`）、标签"线路正常"、环与摘要栏 pill 用注意色；有 `down` 同样显示分数但用异常色。跨境站**不再**有"后台体验 92"这种没有计算口径的分数；浏览器测速里原始源超时是预期现象（那正是改写的原因），不计入环。恢复模式下环为灰色、中央 `—`、标签"已停用"。
- **Hero 右侧事实条**：每项 `标签 值`，不换行（`white-space: nowrap`），放不下就整项换行；最多三项，值优先是数字。
- **页头右侧只放"帮助 / 反馈"两个幽灵链接；页脚只放版本 + 运行时长 + 更新日志 + wpcy.com。** 不在三处重复同一链接。

**四个状态**（都在原型里，右下角深色切换器是原型专用，不属于产品）：

| 状态 | 文件 | 要点 |
|------|------|------|
| 国内站正常 | `overview-domestic` | 环 100；四条线路全绿；时间线里可以有已恢复的历史事件 |
| 跨境站正常 | `overview-crossborder` | 环 92（后台体验）；有"绑定本站"下一步条，所以 Hero 按钮全次级 |
| 降级 | `overview-degraded` | 镜像不可达已回退：Hero 标题直接说发生了什么和"不需要你操作"；环 `3/4` 注意色；下一步条换成一条注意色提示 + "立即重试"次按钮；线路列表第一行注意色并写明回退目标与耗时 |
| 刚安装 | `overview-empty` | 统计卡数字位写"还没有数据"（20px 弱色），说明写**何时会有**；时间线两条（首次检查完成 / 已按场景配置）；页脚"刚安装" |
| 恢复模式 | `overview-recovery` | 页面最顶一条注意色横幅（`.notice.warn.act`）："恢复模式已开启：全部 URL 改写与模块已停用……" + "退出恢复模式"次按钮；Hero 标题改为"恢复模式已开启，叶子现在什么都不做。"，环灰色 `—`"已停用"，事实"镜像 未接管 · 加速 0 项"；其余段照常显示历史数据 |
| 升级站未选场景 | `overview-upgraded` | 国内站正常态 + 一条"下一步"条："确认你的站点场景。从 3.8 升级的站点先按「国内站」运行……" + 主按钮"确认你的站点场景"→ 设置页。此时 Hero 按钮全次级（一页一个主按钮） |

**服务页四态**（`services` / `services-pending` / `services-bound` / `services-unreachable`）：绑定中 = 状态卡标题"正在绑定本站"、大字"等待验证"前带 18px 旋转环 `.spin`、唯一动作"取消"（次级）；服务端不可达 = 已绑定页顶部一条注意色横幅"暂时无法连接文派服务，显示的是 N 小时前的状态。加速功能不受影响。" + "重试"，小工具区换成空态"小工具目录暂时不可用。连接恢复后会自动显示……"。

**设置页网络只读态**（`settings-network`，多站点子站管理员）：lede "已由网络设定 · 本站不能单独修改"，无简单/高级切换；页首一条信息提示说明找网络管理员开放「允许子站覆盖」；每张卡标题右侧灰 pill"已由网络设定"；全部控件禁用（开关 50% 透明，场景卡 60% 透明且 `disabled`）；不显示"重新运行向导"与"我们建议"。

### 5.2 设置

三张卡：**站点场景**（三张选择卡 + 一条"切换会重置默认组合 / 我们建议：…"提示）；**连通性**（字段行：WordPress.org 源 / 公共前端库（分段作用域 + 复选）/ 后台头像 / 前台头像 / 字体 Windfonts / 后台加速（禁用 + "即将提供"））；**后台体验**（减少后台心跳 / 不加载仪表盘的外部内容）。页首写"改动即时生效，不需要保存"；保存回执为控件旁 12px 绿字"已保存 ✓"。

文案与控件规则：

- **开关的文字标签只表达开/关**（"已开启 / 未开启"）。作用域用单独的灰色小标签 `.scope`（"只在后台"）放在开关左侧；不能用的原因也用 `.scope`（可为链接，如"绑定本站后可用"）。
- **单选项名说的是它做什么，不说"自动 / 关闭"**：WordPress.org 源 = "国内镜像 / 直连 WordPress.org"，说明里标"国内站默认 / 跨境站默认"。不用"（推荐）"——推荐由场景决定，写在说明里。
- 简单模式里由场景自动决定、用户不能改的项，用状态 pill 显示**当前实际值**（"直连 WordPress.org"），不是"自动"。
- 简单 / 高级两处描述同一开关时措辞必须一致（简单模式"减少后台心跳"，高级模式也叫"减少后台心跳"）。
- 中文文案里的引用用「」，不用直引号。

### 5.3 服务（两态）

未绑定：一张状态卡（匿名绑定说明 + 主按钮）+ 小工具空状态。已绑定：站点卡（标识 + 绑定日期 + 解除）→ 可用服务行列表（`.rows.svc`：三列栅格 `1fr / 88px / 72px`，状态 pill 和动作各成一列对齐）→ 小工具四列格。商业措辞只用"了解 →"。露出哪些服务由服务端规则决定（场景 + WooCommerce 检测），原型示例为跨境 Woo 店。页面 lede 是产品文案（"文派服务与小工具，按站点场景显示"），不放原型控件。

### 5.4 诊断

四组：从你的服务器到各源（表）→ 从你的浏览器到各源（表 + 一条解读提示）→ 记录（迁移记录 / 出站主机记录）→ 数据与恢复（进入恢复模式 / 小工具数据）。**小节标题右侧同时放说明和动作链接**（`.sec-r`：说明 + "立即检查 / 重新测速"），表卡不再有自己的卡标题——避免"小节标题 + 卡标题"双重标题。页头右侧"导出诊断报告"。用户可见文案不出现内部代号（"云桥"→"文派服务 · 绑定与小工具"）。

### 5.5 首次向导（4 步）

站点场景（三张选择卡 + 建议提示）→ 已为你做的（绿勾行列表）→ 绑定本站（两行价值 + 主按钮 / "暂不"）→ 一切就绪（三张 `.stat-a` 摘要卡：图标 + 标签 / 大字值 / 一句说明，**没有图表**——刚安装没有数据可画）。无横向标签；步骤条在顶。

### 5.6 恢复模式

单卡：琥珀图标块 + 标题 + "不依赖 JavaScript" 说明 + 一句"先试第一项，不够再用第二项" + 两行动作（`.rows.recover`）：**只关闭 URL 改写**（次按钮；说明它保留什么）→ **停用全部模块**（`.btn-danger` 白底红边红字；说明它相当于停用插件但保留设置）→ 卡脚"返回概览"。破坏性动作不用主蓝。服务端渲染，样式内联同规格。

## 6. 文案规则（摘自 `docs/dev/copy-guidelines.md`）

说"为你做了什么"；短句；不出现"配额 / 遥测 / 隐私 / 上报 / 占位 / 暂无数据"；错误用"暂时无法 X，Y"；英文只留专有名词；商业链接一律"了解 →"。

## 7. 实现映射（给 M-UI）

`@wordpress/components` 对应：卡 = `Card/CardHeader/CardBody/CardFooter`（自定样式覆盖圆角与阴影）；分段控件 = `ToggleGroupControl`；开关 = `ToggleControl`；单选 = `RadioControl`；表格 = `DataViews` 表格布局；提示 = `Notice`（去边框化）；按钮 = `Button` variant primary/secondary/tertiary。字阶与颜色以 CSS 变量注入 `.wpcy-app` 作用域，不改全局。

## 8. 不做什么

深色模式、移动端、动效、品牌大标语区、横幅式商业内容、第二根侧栏。
