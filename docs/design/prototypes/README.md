# 已认可原型归档

经产品负责人（feibisi）书面认可的 HTML 原型放在本目录的子目录：`docs/design/prototypes/<页面>/`。规则见 [`docs/dev/design-sop.md`](../../dev/design-sop.md)。

本目录在门禁生效时建立。当前静态稿仍在 [`../mockups/`](../mockups/)，那些文件**不是**本门禁的认可记录；新的 UI 任务必须按设计 SOP 重新认可并归档到这里。

每个页面子目录至少含：

- 每个状态一份 HTML（空 / 正常 / 加载 / 错误 / 降级 / 多站点如适用），文案为原文
- `APPROVAL.md`（谁、何时、原话、规格编号）
- `README.md`（页面、规格编号列表、与 `admin-ui-spec.md` 的对应）
